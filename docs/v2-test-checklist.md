# V2 Test Checklist

1. Open `/v2` in a fresh browser/session.
2. Confirm the welcome screen explains that this is a fun simulation, not business validation.
3. Confirm the objective explains the loop: decide → see impact → adapt → grow.
4. Name the café and confirm the name appears during play.
5. Test an intentionally over-budget setup. The UI should show negative cash and explain how to fix it before opening.
6. Open the café and confirm key metrics are visible before decisions.
7. Play several days and verify decisions advance the same session.
8. Confirm `Start new game` creates a fresh run while the prior run remains saved.
9. Trigger feedback and test both Submit and Maybe later.
10. Watch for repeated scenarios, especially weather, and note whether important decision types are missing after 20 days.
11. Check whether earlier decisions appear to have consequences later in the run.

This V2 is intentionally focused on the core café simulation. Multi-business, franchise, collaboration, and community features are not part of this test build.
